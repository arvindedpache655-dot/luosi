🛠️ 如何在 GitHub 仓库自动编译出 APK？

  1. 解压下载好的 ScrewPuzzle-Android-GitHub.zip。
  2. 在 GitHub 新建一个仓库，把解压出来的所有文件夹（包含 .github、app、build.gradle 等）上传并 Push 到仓库。
  3. 点击 GitHub 仓库顶部的 「Actions」 标签页，工作流会自动开始编译，约 1~2 分钟完成后即可在 Artifacts 处直接下载编译好的 ScrewPuzzle-debug.apk 与签名版 ScrewPuzzle-release-signed.apk！
